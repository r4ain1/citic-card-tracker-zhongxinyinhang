# 中信银行信用卡账单结构与数据解析规范

## 1. 网银账单导出页面与接口

- 账单查询主页面: `https://e.creditcard.ecitic.com/citiccard/ebank-ocp/ebankpc/bill.html`
- 已出账单下载接口: `/citiccard/ebank-ocp/pcBill/downloadSettleBills`
  - 参数: `cardNbr`, `stmtDate`, `acctPdt`, `acct`, `currCode`
  - 默认下载文件名: `已出账单明细.xls`
- 未出账单下载接口: `/citiccard/ebank-ocp/pcBill/downloadUnSettleBills`
  - 参数: `cardNbr`, `currCode`, `acct`
  - 默认下载文件名: `未出账单明细.xls`

## 2. 导出 Excel 文件格式特征

中信网银导出的 `.xls` 文件具有以下两类常见形态：

1. **HTML 伪 Excel 格式**: 文件后缀为 `.xls`，但内容为 UTF-8 或 GBK 编码的 HTML `<table>` 结构。解析器必须首先尝试 `pd.read_html()`。
2. **标准 BIFF8 / Excel 二进制格式**: 使用 `xlrd` 引擎或 `openpyxl` 引擎打开。

## 5. 支出与退款判断逻辑

- **支出 (Expense)**: 金额为正数，且描述不含退款/还款关键词。
- **退款/还款 (Refund)**: 
  - 金额带有负号 `-` 或括号 `(100.00)` 或 `CR`。
  - 描述包含关键词：`退款`, `还款`, `退货`, `冲正`, `撤销`, `退回`, `返还`, `贷记`。
- **净支出计算**: `净支出 = 支出总额 - 退款总额`。活动达标严格基于净支出计算，避免因退款导致未真实达标而被银行追回奖励。
