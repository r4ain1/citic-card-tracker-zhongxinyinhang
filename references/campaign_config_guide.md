# 信用卡活动消费达标监控配置指南

用户参加中信银行（或其他银行）活动时，常常有以下几类常见门槛要求：
1. **当月全渠道总累计消费满额**: 例如当月满 10,000 元返 100 元刷卡金。
2. **特定快捷支付渠道消费满额**: 例如微信支付累计满 5,000 元、支付宝累计满 3,000 元。
3. **单笔消费门槛要求**: 例如云闪付累计消费满 2,000 元，但要求单笔消费必须满 10 元。
4. **指定卡片消费**: 例如名下某张特定白金卡或联名卡累计消费满额免年费。

在 `config.yaml` 中，可以通过简单的 YAML 字典配置任意多个活动规则：

```yaml
campaigns:
  # 规则示例 1: 全渠道消费达标
  - id: "cmp_total_10k"
    name: "10月刷卡金达标"
    target_amount: 10000.0        # 达标金额
    channels: []                  # 留空表示全部渠道
    cards: []                     # 留空表示所有卡
    min_single_amount: 0.0        # 0 表示无单笔门槛
    description: "月度累计净消费满10,000元"

  # 规则示例 2: 微信支付专享返现
  - id: "cmp_wechat"
    name: "微信支付专享活动"
    target_amount: 5000.0
    channels: ["微信支付"]         # 必须包含在识别渠道列表中
    cards: []
    min_single_amount: 0.0
    description: "微信渠道消费满5000元"

  # 规则示例 3: 云闪付单笔满10元活动
  - id: "cmp_upay_with_limit"
    name: "云闪付天天享礼"
    target_amount: 2000.0
    channels: ["云闪付"]
    cards: []
    min_single_amount: 10.0       # 过滤掉低于10元的小额支付
    description: "云闪付单笔满10元，累计达标2000元"

  # 规则示例 4: 指定卡号尾号消费
  - id: "cmp_specific_card"
    name: "白金卡年费达标"
    target_amount: 60000.0
    channels: []
    cards: ["8888"]               # 仅统计尾号为 8888 的卡片
    min_single_amount: 0.0
    description: "尊尚白金卡年消费满6万元免年费"
```

## 达标监控算法与输出指标

系统在每次运行时，会自动计算：
- **当前累计净消费**: `符合条件的支出 - 符合条件的退款`（严格防止退款导致假达标）。
- **完成百分比**: `(当前消费 / 目标金额) * 100%`。
- **还差金额**: `目标金额 - 当前消费`。
- **剩余天数与建议日均消费**: 若当月还剩余 N 天，计算 `还差金额 / N 天`，明确告知用户每天需要再刷多少即可稳妥达标！
